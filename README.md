# Serv Granja — Petshop & Veterinária

Site estático pronto para publicação na Hostinger.

## Deploy

Os arquivos de produção ficam diretamente na raiz do repositório:

- `index.html`
- `styles.css`
- `app.js`
- `assets/`

Não há dependências, etapa de build ou necessidade de Node.js. Na Hostinger, basta importar/conectar este repositório e publicar a raiz do projeto.

## Desenvolvimento local

Você pode abrir `index.html` diretamente no navegador ou iniciar um servidor HTTP local.

Exemplo com Python:

```bash
python -m http.server 4173
```

Depois acesse `http://localhost:4173`.
